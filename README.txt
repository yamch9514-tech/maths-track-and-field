Maths Track & Field (version 3)

WHERE TO PUT IT
Put every file in this folder into its own GitHub repository (for example
"maths-track-and-field") and switch on GitHub Pages for it. The game is then at
https://YOUR-GITHUB-NAME.github.io/maths-track-and-field/
Students open that link on their phone and choose Install / Add to Home Screen.

SAVED PROGRESS
Progress is saved on each phone. Students can copy a save code from the Me tab
to move their medals to a new phone. Phones that played version 2 keep their
medals, XP, streak and notebook when they update.

CLASS LEADERBOARD (optional)
config.js holds the leaderboard settings. It is switched off until you paste your
Google Apps Script web app URL and key into it (see the setup guide and Code.gs).
When you download a new version of the game later, keep your own config.js.

UPDATING
After changing any file, change 'mtf-v3' in sw.js to 'mtf-v4' (and so on), so
phones pick up the new version. config.js is always fetched fresh when online.
